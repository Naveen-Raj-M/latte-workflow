# LATTE Analysis Module Documentation

This module provides comprehensive analysis tools for LATTE tomography results, including travel time residual analysis, velocity model comparisons, and distance-dependent analysis.

## Overview

The analysis module processes CSV files generated by the post-processing pipeline and creates professional visualizations and statistical reports. It is organized into four main analysis components:

1. **Travel Time Analysis** - Residual statistics, phase comparisons, and ratio analysis
2. **Velocity Analysis** - Model comparisons with spatial projections and profile analysis  
3. **Distance Analysis** - Distance-dependent residual analysis with correlation studies
4. **Short Distance Analysis** - Focused analysis of short source-receiver distances

## Quick Start

### Basic Execution

All analysis is controlled through YAML configuration files with no command-line arguments:

```bash
# Run complete analysis pipeline
python -m analysis.main

# Use specific configuration
python -m analysis.main --config-name analysis/high_quality

# Run single analysis module
python -m analysis.main --config-name analysis/travel_time_only
```

### Configuration Override

Use Hydra's override syntax to modify settings without editing files:

```bash
# Change output format and quality
python -m analysis.main analysis.output_format=pdf analysis.dpi=600

# Enable debug logging
python -m analysis.main analysis.log_level=DEBUG

# Run single function via override
python -m analysis.main single_function=velocity_analysis

# Multiple parameter changes
python -m analysis.main analysis.output_format=pdf analysis.dpi=600 \
  analysis.plot_style.font_size=16 single_function=travel_time_analysis
```

## Analysis Modules

### Travel Time Analysis

**Purpose**: Comprehensive analysis of travel time residuals between observed and synthetic data.

**Input Requirements**:
- Travel time CSV with columns: `observed_tt`, `synthetic_tt`, `residual_s`, `phase`, `station`, `event_id`

**Key Features**:
- Phase-specific (P-wave vs S-wave) statistical analysis
- Residual distribution analysis with outlier detection
- Logarithmic ratio analysis for multiplicative error assessment
- Log-log scale comparisons for dynamic range evaluation
- Station and event-based residual grouping

**Generated Outputs**:
- `synthetic_vs_observed.png` - Scatter plots with 1:1 reference lines and correlation statistics
- `residual_histograms.png` - Distribution analysis with statistical overlays
- `ln_ratio_analysis.png` - Logarithmic ratio distributions and vs-time plots
- `synthetic_vs_observed_loglog.png` - Log-scale comparisons for dynamic range
- `travel_time_analysis_report.txt` - Comprehensive statistical summary

**Configuration Options**:
```yaml
travel_time_analysis:
  enable_log_log_plots: true        # Log-scale visualization
  enable_ln_ratio_analysis: true    # Multiplicative error analysis
  outlier_threshold_sigma: 3.0      # Statistical outlier detection
  histogram_bins: 50                # Histogram resolution
  max_plot_points: 50000           # Performance optimization
```

### Velocity Analysis

**Purpose**: Detailed comparison between two velocity models with spatial and statistical analysis.

**Input Requirements**:
- Two velocity CSV files with columns: `vp`, `vs`, `X_grid_km`, `Y_grid_km`, `Z_grid_km`, `i`, `j`, `k`

**Key Features**:
- Multi-dimensional velocity difference analysis
- Spatial RMS projections across XY, XZ, and YZ planes
- Vertical profile analysis at locations of extreme differences
- Horizontal slice comparisons at significant depths
- Geometric mean ratio analysis for velocity changes
- Vp/Vs ratio evolution tracking

**Generated Outputs**:
- `basic_velocity_comparison.png` - Scatter plots and difference histograms
- `spatial_velocity_projections.png` - RMS spatial distribution maps
- `spatial_geometric_ratio_projections.png` - Ratio-based spatial analysis
- `velocity_vertical_profiles.png` - 1D profiles at extreme locations
- `velocity_comparison_report.txt` - Statistical comparison summary

**Configuration Options**:
```yaml
velocity_analysis:
  comparison_mode: "initial_vs_final"    # "initial_vs_final", "method_comparison", "custom"
  compute_log_ratios: true               # Logarithmic ratio analysis
  enable_spatial_projections: true       # 2D spatial mapping
  interpolation_method: "cubic"          # Spatial interpolation quality
  grid_resolution: 100                   # Spatial grid density
```

### Distance Analysis

**Purpose**: Investigation of travel time residual dependencies on source-receiver distance.

**Input Requirements**:
- Travel time CSV, station coordinates CSV, event coordinates CSV

**Key Features**:
- 3D Euclidean distance calculation (transformed or original coordinates)
- Distance-residual correlation analysis with trend fitting
- Binned distance statistics with error bar visualization
- Travel time ratio analysis as function of distance
- Phase-specific distance dependency investigation

**Generated Outputs**:
- `residuals_vs_distance.png` - Residual-distance relationships with trend lines
- `ratios_vs_distance.png` - Travel time ratios vs distance (linear and log scale)
- `distance_analysis_report.txt` - Correlation and trend analysis summary

**Configuration Options**:
```yaml
distance_analysis:
  coordinate_type: "transformed"      # "transformed" or "original"
  enable_ratio_analysis: true        # Ratio vs distance analysis
  distance_bins: 20                  # Binning resolution
  correlation_method: "pearson"      # Statistical correlation method
```

### Short Distance Analysis

**Purpose**: Specialized analysis for short source-receiver distances with spatial visualization.

**Input Requirements**:
- Travel time CSV, station coordinates CSV, event coordinates CSV

**Key Features**:
- Distance-based data filtering with configurable cutoff
- Travel path visualization with residual-based color coding
- Spatial clustering analysis for geographic regions
- Zoom region analysis for detailed investigation
- Residual intensity mapping for spatial patterns

**Generated Outputs**:
- `short_distance_travel_paths_[coord].png` - Spatial path visualization
- `short_distance_histograms.png` - Residual distributions and statistics
- `short_distance_correlation_[coord].png` - Distance-residual relationships
- `zoom_cluster_[name]_[coord].png` - Detailed regional analysis
- `short_distance_analysis_report.txt` - Spatial analysis summary

**Configuration Options**:
```yaml
short_distance_analysis:
  distance_cutoff_km: 20.0           # Maximum distance for inclusion
  coordinate_type: "transformed"     # Coordinate system choice
  show_travel_paths: true            # Path visualization
  enable_zoom_clusters: true         # Regional detailed analysis
  zoom_clusters:                     # Configurable analysis regions
    - name: "Central_Region"
      x_min: 350.0
      x_max: 450.0
      y_min: 300.0
      y_max: 400.0
```

## Troubleshooting

### Common Configuration Issues

1. **Missing Input Files**
   ```bash
   # Check file paths in configuration
   ls -la data/processed/
   
   # Disable validation temporarily
   python -m analysis.main quality_control.validate_input_data=false
   ```

2. **Memory Issues**
   ```yaml
   analysis:
     plot_style:
       max_plot_points: 20000    # Reduce data density
   
   velocity_analysis:
     grid_resolution: 50         # Lower spatial resolution
   ```

3. **Output Permission Issues**
   ```bash
   # Ensure output directories are writable
   chmod 755 results/analysis/
   ```

Create workflow-specific configurations:

```yaml

  - default

  enabled: true
```

### Parameter Sweeps

```bash
# Test different distance cutoffs
for cutoff in 10 20 30; do
  python -m analysis.main --config-name analysis/short_distance_only \
    short_distance_analysis.distance_cutoff_km=$cutoff \
    short_distance_analysis.output_dir=results/analysis/short_${cutoff}km
done
```

### Batch Processing

```bash
# Process multiple model comparisons
for model in model_run1 model_run2 model_run3; do
  python -m analysis.main --config-name analysis/velocity_only \
    velocity_analysis.model2_csv=data/processed/${model}_velocity.csv \
    velocity_analysis.output_dir=results/analysis/${model}_comparison
done
```
